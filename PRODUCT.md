# koative organization profile

Public GitHub organization overview in English. It says what koative is, lists the public products, and links to the studio and the contact page. It speaks as the studio: the founder's name and personal accounts are not on it (Koray, 2026-11-01).

- **Name:** `koative`, always lowercase in copy. The legal name Koative LLC appears only in legal text.
- **Copy:** headline “We build software products, most of them open source.” and the line “koative is an independent software studio, a US company. We also take on a few client projects a year.” Plain tone: no slogans, superlatives, invented numbers, stars or metrics.
- **Products:** list exactly the public products, OpenMacApps, Bucketdeck, Cento, Rast and hyperliquid-go, each with its fixed emoji (🍎 🪣 💯 🖼️ 🐹), the one-liner from https://koative.com/products.json, its website and its `koative/` repository. The OpenMacApps count is always written “1,000+”. Private or unreleased projects stay off the profile.
- **Links:** koative.com, https://koative.com/contact/ and the LinkedIn company page. No X link (the @koative account on X is not ours, and the founder's account is personal).
- GitHub Markdown is the delivery surface. No JavaScript, custom page CSS, third-party badge services or activity feeds. Images are self-contained and work in both GitHub colour schemes. Every link must resolve.

# Profile assets

`koative-header-light.svg` and `koative-header-dark.svg` share a 1000 × 288 view box. The `-mobile` variants use 512 × 240 so the headline stays readable on phones. All four are generated by `scripts/generate_header.py`; don't edit them by hand.

- **Logo:** the koative two-lobe mark and lowercase wordmark, embedded unchanged from the studio's brand files `logo-void.svg` (light header) and `logo-light.svg` (dark header).
- **Lettering:** Clash Grotesk 500 (headline) and Switzer 400 (label) by Indian Type Foundry, used under the ITF Free Font License ([Clash Grotesk](https://www.fontshare.com/fonts/clash-grotesk), [Switzer](https://www.fontshare.com/fonts/switzer)). The font files are **not** kept in this repository. The generator reads the TTFs from a local folder and writes the glyphs as outlined paths, so the published SVGs contain no font data, remote fonts, images or scripts.
- **Colour:** grounds `#08080a` and `#f2f1ee`; the soft corner glow uses the brand blue `#2F3BFF`, violet `#B44BD6` and coral `#FF5B45`.

## Regenerating

The generator needs `fonttools`, the brand SVG folder and the font folder:

```sh
python3 -m pip install fonttools
python3 scripts/generate_header.py \
  --brand /path/to/koative/brand/svg \
  --fonts /path/to/koative/src/assets/fonts
```

`--brand` and `--fonts` can also be set with `KOATIVE_BRAND_DIR` and `KOATIVE_FONT_DIR`. They default to `/home/hermes/dev/koative/brand/svg` and `/home/hermes/dev/koative/src/assets/fonts`. The output is deterministic: the same inputs reproduce the committed SVGs byte for byte.

When a header changes, publish it under a new file name and update `profile/README.md`. GitHub's image cache can keep serving the old file under an unchanged name.

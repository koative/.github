# koative profile

The org profile carries the studio identity from koative.com: the two-lobe blue–violet–coral mark, the lowercase wordmark, Clash Grotesk and Switzer, void and light grounds.

- **Header:** a rounded card. Logo top left, the headline “We build software products, most of them open source.” in Clash Grotesk 500 beneath it. Desktop view box 1000 × 288 with the headline on two lines and a small Switzer 400 “Independent software studio” label aligned to the wordmark baseline on the right. Mobile view box (at most 600px viewport width) 512 × 240 with the headline on three lines and no label.
- **Grounds:** light `#f2f1ee` with `#08080a` ink, dark `#08080a` with `#f2f1ee` ink. Muted label `#5c5b58` / `#a3a29e`.
- **Gradient:** one soft glow built from the blue `#2F3BFF`, violet `#B44BD6` and coral `#FF5B45` stops, in the lower right on desktop and the upper right on mobile. It stays clear of the lettering. No animation.
- **Logo:** embedded unchanged from the brand SVGs (`logo-void.svg` on light, `logo-light.svg` on dark), scaled uniformly.
- **README:** header, one line of copy, a five-row product table (emoji, name, one-liner, website and source links), one footer line of links. Native GitHub Markdown supplies the rest of the spacing and colour.

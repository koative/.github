# Koative profile

A compact extension of the existing studio identity: its blue–violet–coral connective mark, lowercase wordmark and “Software, made together.” line.

- Header view box: 1000 × 128 on desktop, 512 × 128 on mobile (at most 600px viewport width). Dark ground `#0d1017`, light ground `#f5f6fa`; matching high-contrast text.
- Manrope 700 wordmark and 450 tagline, outlined for reliable GitHub rendering; licensed font kept locally for regeneration.
- One four-second traced outline on the right echoes the original connective symbol. No looping animation; reduced motion disables it.
- Public project links use native GitHub text and a two-by-two compact table. The repository list below remains the main content.
- Native Markdown controls the surrounding spacing and colors. No external badge dependency or duplicated repository statistics.
